Valores que no puede tomar x

Método

Solo importa el denominador: factorizalo e igualá cada factor a cero. Esos valores son los prohibidos.

a) (x − 3)/(x + 5): x + 5 = 0 ⇒ x = −5. Entonces x ≠ −5.

b) 2x² − 2x − 4 = 2(x² − x − 2) = 2(x − 2)(x + 1)x ≠ 2 y x ≠ −1
c) El denominador es x.x ≠ 0
d) x³ + x² − 17x + 15. Con Gauss probamos 1: 1 + 1 − 17 + 15 = 0. Ruffini da x² + 2x − 15 = (x + 5)(x − 3). Queda (x − 1)(x − 3)(x + 5).x ≠ 1, x ≠ 3, x ≠ −5

  3. Restricciones: x ≠ −2, x ≠ 3, x ≠ −3.

    2(x + 1)(x − 2)(x − 3)3(x + 2)(x − 3)(x + 3) = 2(x + 1)(x − 2)3(x + 2)(x + 3)

Ejercicio 4 · página 46

Multiplicar

Método · inciso a

  1. Factorizamos todo: x⁴ − 2x³ = x³(x − 2), x² − 4 = (x − 2)(x + 2), x² + 4x + 4 = (x + 2)².
  2. Restricciones: x ≠ 2, x ≠ −2.
  3. Una sola fracción y tachamos pares (cada color con su pareja):
    x³(x − 2) · x(x + 2)(x − 2)(x + 2) · (x + 2)² = x⁴(x + 2)²

Abajo había (x + 2) tres veces y arriba una: se tacha una y quedan dos, (x + 2)².

b) x⁵ + 32 se divide por x + 2 con Ruffini (porque (−2)⁵ + 32 = 0) y el cociente es justo el otro denominador: x⁵ + 32 = (x + 2)(x⁴ − 2x³ + 4x² − 8x + 16). Con x² − 1 = (x − 1)(x + 1):
(x + 2)(x⁴ − … + 16)x − 1 · (x − 1)(x + 1)x⁴ − … + 16 = (x + 2)(x + 1)
x ≠ 1. El polinomio de grado 4 nunca vale cero en los reales: es (x⁵ + 32)/(x + 2), que solo podría anularse en x = −2, y ahí vale 80.
c) x(x − 1)(x + 3) · x⁵(x + 2) sobre (x − 1)(x − 5)(x + 2) · x²(x² + 3). El denominador de la primera sale con Gauss (x = 1).
x⁴(x + 3)(x − 5)(x² + 3)
x ≠ 0, x ≠ 1, x ≠ 5, x ≠ −2 (x² + 3 nunca es cero)
d) 2x³ − 2 = 2(x − 1)(x² + x + 1); 4x² + 4x − 8 = 4(x + 2)(x − 1); x³ + 5x² + 5x − 2 = (x + 2)(x² + 3x − 1) (Gauss con −2); x⁵ − x² = x²(x − 1)(x² + x + 1).
x² + 3x − 12x²(x − 1)
x ≠ 0, x ≠ 1, x ≠ −2

Dividir

Método · inciso b

Empezamos por el b porque es el que sale «limpio» (ver la nota del a y el c).

  1. Factorizamos los cuatro: x³ − 6x² + 11x − 6 = (x − 1)(x − 2)(x − 3); x² − x − 6 = (x − 3)(x + 2); x³ + 2x² − 13x + 10 = (x − 1)(x − 2)(x + 5); x³ + x² − 25x − 25 = (x + 1)(x − 5)(x + 5).
  2. Restricciones: los dos denominadores y el numerador del divisor. Da x ∉ {−5; −2; −1; 1; 2; 3; 5}.
  3. Damos vuelta la segunda y tachamos:
    (x − 1)(x − 2)(x − 3)(x − 3)(x + 2) · (x + 1)(x − 5)(x + 5)(x − 1)(x − 2)(x + 5) = (x + 1)(x − 5)x + 2
a) x(x − 2)(x + 3) / (x⁴(x − 2)(x + 5)) · (x − 25) / ((x − 3)(x + 3)²)
x − 25x³(x + 5)(x − 3)(x + 3)
x ∉ {−5; −3; 0; 2; 3; 25}

Posible errata: el x − 25 del enunciado no se cancela con nada, cuando todo lo demás está armado para simplificar. Si fuera x − 3, quedaría 1/(x³(x + 5)(x + 3)). Lo resolvimos tal como está impreso.

c) x³ − 3x² + 4 = (x + 1)(x − 2)²; x⁴ + x³ − 3x² − 5x − 2 = (x + 1)³(x − 2); x³ − 3x + 2 = (x − 1)²(x + 2); x³ − 5x² + 4x + 4 = (x − 2)(x² − 3x − 2).
(x − 1)²(x + 2)(x + 1)²(x² − 3x − 2)
x ∉ {−2; −1; 1; 2} y x ≠ (3 ± √17)/2

Posible errata: el último polinomio deja un trinomio sin raíces racionales. Si fuera x³ − 5x² + 8x − 4 = (x − 1)(x − 2)², quedaría (x − 1)(x + 2)/((x + 1)²(x − 2)). Lo resolvimos tal como está impreso.

d) x²(x − 1)(x² + x + 1) / (x(x − 3)(x + 2)) · x²(x − 3) / (x − 1)²
x³(x² + x + 1)(x + 2)(x − 1)
x ∉ {−2; 0; 1; 3}

Sumar y restar con distinto denominador

Método · inciso a

2x3x + 3 + 4x + 1 − 5x + 1x² − 1

1. Factorizamos los denominadores: 3x + 3 = 3(x + 1); x + 1 ya está; x² − 1 = (x + 1)(x − 1).

2 a 4. Armamos el denominador común con cada factor distinto una sola vez, le agregamos a cada fracción lo que le falta y juntamos los numeradores:

5. Operamos el numerador (el menos cambia los dos signos de 3(5x + 1) = 15x + 3):

2x² − 2x + 12x − 12 − 15x − 3 = 2x² − 5x − 15

¿Se simplifica? Solo si el numerador se anula en 1 o −1: 2 − 5 − 15 ≠ 0 y 2 + 5 − 15 ≠ 0. No.

a) 2x² − 5x − 153(x + 1)(x − 1) con x ≠ 1, x ≠ −1.

b) −3/x − (x + 1)/x³ + 2/(x + 2). Entre x y x³ va la potencia mayor, x³: a x le falta x².

Numerador: −3x³ − 6x² − (x² + 3x + 2) + 2x³ = −x³ − 7x² − 3x − 2. No se anula en 0 ni en −2, así que no se simplifica.

b) −x³ − 7x² − 3x − 2x³(x + 2) con x ≠ 0, x ≠ −2.

c) 3x/(x(x + 1)) + (x − 1)/(x + 1) − 2x/(3x + 3), con 3x + 3 = 3(x + 1).

Numerador: 9x + 3x² − 3x − 2x² = x² + 6x = x(x + 6). Se tacha la x con la de abajo:

x(x + 6)3x(x + 1) = x + 63(x + 1)

c) x + 63(x + 1) con x ≠ 0, x ≠ −1.

Atajo: la primera fracción se podía simplificar antes, 3x/(x(x + 1)) = 3/(x + 1), y el denominador común quedaba 3(x + 1). Pero el x ≠ 0 no se pierde.

d) 2x + 1 + 2/(x + 5) − (x + 3)/(x² − 25). El término entero 2x + 1 es una fracción con denominador 1: le falta todo.

Numerador: (2x + 1)(x² − 25) + 2x − 10 − x − 3 = 2x³ + x² − 50x − 25 + x − 13 = 2x³ + x² − 49x − 38. No se anula en 5 ni en −5.

d) 2x³ + x² − 49x − 38(x − 5)(x + 5) con x ≠ 5, x ≠ −5.

e) 2x/(x + 2) + (3x + 1)/(3x + 6) − 2/(x − 5), con 3x + 6 = 3(x + 2).

Numerador: 6x² − 30x + (3x² − 14x − 5) − (6x + 12) = 9x² − 50x − 17. No se anula en −2 ni en 5.

e) 9x² − 50x − 173(x + 2)(x − 5) con x ≠ −2, x ≠ 5.

f) 2x/(x − 3) − (5x + 1)/(x + 2) + 2. El 2 es 2/1.

Numerador: 2x² + 4x − (5x² − 14x − 3) + 2x² − 2x − 12 = −x² + 16x − 9. No se anula en 3 ni en −2.

f) −x² + 16x − 9(x − 3)(x + 2) con x ≠ 3, x ≠ −2.

Dominio

Método · inciso a

Se saca el valor que anula el denominador. Con fracciones en los coeficientes, la cuenta es la misma: ½x + 3 = 0 ⇒ ½x = −3 ⇒ x = −6.

a) Dom f = ℝ − {−6}

b) 3x − ¼ = 0 ⇒ x = 1/12 → ℝ − {1/12}
c) x − ½ = 0 ⇒ x = 1/2 → ℝ − {1/2}
d) 3x + 4 = 0 ⇒ x = −4/3 → ℝ − {−4/3}

Conjunto imagen

Método · inciso a

c) a/c = 1/2 → ℝ − {1/2}

Ejercicio 11 · página 48

Escribir una función con esas asíntotas

Método · inciso a

  1. La A.V. arma el denominador: si es x = 2, el denominador tiene que anularse en 2: x − 2.
  2. La A.H. elige el coeficiente de arriba: a/c = 1 con c = 1 obliga a a = 1.
  3. El término independiente de arriba es libre, siempre que no haga a·d − b·c = 0. Elegimos b = 1: 1·(−2) − 1·1 = −3 ≠ 0. ✓

a) f(x) = (x + 1)/(x − 2). Hay infinitas respuestas: sirve cualquier (x + b)/(x − 2) con b ≠ −2.

b) A.V. x = −1/4: el denominador 4x + 1 se anula ahí (y evita fracciones). Con c = 4, la A.H. 1/2 pide a = 2. Elegimos b = 3: 2·1 − 3·4 = −10 ≠ 0. ✓

f(x) = (2x + 3)/(4x + 1). Sirve cualquier (2x + b)/(4x + 1) con b ≠ 1/2.

Preimágenes de h(x) = (5x + 2)/(3x − ½)

Método · inciso c

Buscar la preimagen de 4 es resolver h(c) = 4: igualás y pasás el denominador multiplicando.

  1. (5c + 2)/(3c − ½) = 4 ⇒ 5c + 2 = 4(3c − ½) = 12c − 2
  2. 2 + 2 = 12c − 5c ⇒ 4 = 7c ⇒ c = 4/7
  3. Control: c = 4/7 ≠ 1/6, que es el valor prohibido. ✓

Para h(a) = 0 alcanza con el numerador: una fracción vale cero cuando su numerador vale cero.

a) 5a + 2 = 0 ⇒ a = −2/5
b) 5b + 2 = −12b + 2 ⇒ 17b = 0 ⇒ b = 0Control: h(0) = 2/(−½) = −4 ✓
d) 5d + 2 = 3d − ½ ⇒ 2d = −5/2 ⇒ d = −5/4
e) 5e + 2 = (9/2)(3e − ½); multiplicando todo por 4: 20e + 8 = 54e − 9 ⇒ 17 = 34e ⇒ e = 1/2
f) 5f + 2 = ¼(3f − ½); multiplicando todo por 8: 40f + 16 = 6f − 1 ⇒ 34f = −17 ⇒ f = −1/2
