Tema 01 · página 27

Factorización y raíces

Ayuda memoria

Factorizar es escribir un polinomio como producto de factores. Una raíz es un valor de x que hace que el producto valga cero.

P(x) = A(x) · B(x)
P(r) = 0 ⇔ r es raíz

Para hallar las raíces, igualá cada factor a cero. La factorización completa termina cuando los factores ya no se pueden descomponer en polinomios de menor grado.

La suma de los grados de los factores debe coincidir con el grado original.

Ejemplo resuelto

Factorizar P(x) = 5x⁴ − 5x³ − 210x² y hallar sus raíces.

  1. Extraemos 5x²: P(x) = 5x²(x² − x − 42).
  2. Buscamos dos números cuyo producto sea −42 y cuya suma sea −1: son −7 y 6.
  3. Entonces x² − x − 42 = (x − 7)(x + 6). Igualamos cada factor a cero.

Resultado: P(x) = 5x²(x − 7)(x + 6). Raíces: 0, 7, −6; el 0 se repite dos veces.

Tema 02 · página 28

Factor común

Ayuda memoria

Buscá lo que aparece en todos los términos: el máximo divisor común de los coeficientes y cada letra con su menor exponente.

ab + ac = a(b + c)

Para comprobarlo, distribuí el factor que sacaste.

Ejemplo resuelto

Factorizar 6x³ − 9x².

  1. El máximo divisor común de 6 y 9 es 3.
  2. Ambos términos contienen x; el menor exponente es 2. Sacamos 3x².
  3. Dividimos cada término: 6x³ ÷ 3x² = 2x y −9x² ÷ 3x² = −3.

Resultado: 6x³ − 9x² = 3x²(2x − 3).

Tema 03 · páginas 28 y 29

Factor común por grupos

Ayuda memoria

Si no hay un factor común en todos los términos, agrupá los que sí lo tienen. Después de extraerlo en cada grupo, debe aparecer un mismo paréntesis.

AP + BP + AQ + BQ
= P(A + B) + Q(A + B)
= (A + B)(P + Q)

Ejemplo resuelto

Factorizar x³ + x² + 5x + 5.

  1. Agrupamos: (x³ + x²) + (5x + 5).
  2. Extraemos factor común en cada grupo: x²(x + 1) + 5(x + 1).
  3. El paréntesis (x + 1) se repite; lo extraemos.

Resultado: x³ + x² + 5x + 5 = (x + 1)(x² + 5).

Tema 04 · páginas 29 y 30

Diferencia de cuadrados

Ayuda memoria

Se usa con dos términos cuadrados separados por una resta. Escribí las raíces cuadradas y armá dos binomios conjugados.

a² − b² = (a − b)(a + b)

La suma de cuadrados a² + b² no sigue esta regla en los reales.

Ejemplo resuelto

Factorizar 9x² − 25 y hallar las raíces.

  1. Reconocemos 9x² = (3x)² y 25 = 5².
  2. Aplicamos la identidad: (3x − 5)(3x + 5).
  3. Igualamos a cero: 3x − 5 = 0 o 3x + 5 = 0.

Resultado: 9x² − 25 = (3x − 5)(3x + 5). Raíces: 5/3 y −5/3.

Tema 05 · páginas 30 y 31

Trinomio cuadrado perfecto

Ayuda memoria

Son tres términos: dos cuadrados y, en el medio, el doble producto de sus raíces cuadradas. El signo del término del medio determina el del binomio.

a² + 2ab + b² = (a + b)²
a² − 2ab + b² = (a − b)²

Verificá siempre el término central: debe ser exactamente ±2ab.

Ejemplo resuelto

Factorizar x² − 10x + 25.

  1. El primer término es x² y el último es 5².
  2. Comprobamos el medio: −2 · x · 5 = −10x.
  3. Como el término central es negativo, usamos (x − 5)².

Resultado: x² − 10x + 25 = (x − 5)². La raíz 5 tiene multiplicidad 2.

Tema 06 · páginas 31 y 32

Cuatrinomio cubo perfecto

Ayuda memoria

Son cuatro términos. Los extremos son cubos; los centrales llevan coeficiente 3. Si es una resta, los signos alternan: +, −, +, −.

(a + b)³ = a³ + 3a²b + 3ab² + b³
(a − b)³ = a³ − 3a²b + 3ab² − b³

Ejemplo resuelto

Factorizar x³ − 6x² + 12x − 8.

  1. Los extremos son x³ y −8 = (−2)³; proponemos (x − 2)³.
  2. Comprobamos los centrales: 3 · x² · (−2) = −6x² y 3 · x · (−2)² = 12x.
  3. Coinciden los cuatro términos con la fórmula.

Resultado: x³ − 6x² + 12x − 8 = (x − 2)³. La raíz 2 tiene multiplicidad 3.

Tema 07 · páginas 32 a 35

Teorema de Gauss y Ruffini

Ayuda memoria

Si un polinomio tiene coeficientes enteros, una raíz racional p/q en forma irreducible debe tener p divisor del término independiente y q divisor del coeficiente principal.

Probá candidatos con el teorema del resto: P(a) = 0 significa que (x − a) es factor. Ruffini permite dividir por ese factor.

En Ruffini usá a: para x + 2, se coloca −2.

Ejemplo resuelto

Factorizar P(x) = 2x³ − 6x² − 12x + 16.

  1. Gauss propone, entre otros, ±1, ±2, ±4. Probamos 1: P(1) = 2 − 6 − 12 + 16 = 0.
  2. Dividimos por x − 1 con Ruffini:
12−6−1216
2−4−16
2−4−160
  1. El cociente es 2x² − 4x − 16 = 2(x² − 2x − 8) = 2(x − 4)(x + 2).

Resultado: P(x) = 2(x − 1)(x − 4)(x + 2). Raíces: 1, 4, −2.

Tema 08 · página 35

Función polinómica y multiplicidad

Ayuda memoria

Una función polinómica de grado n tiene como máximo n raíces reales distintas. En la forma factorizada, el exponente de cada factor indica cuántas veces se repite su raíz.

y = a(x − r₁)m₁(x − r₂)m₂…

Multiplicidad par: la curva toca el eje x y vuelve. Multiplicidad impar: lo atraviesa.

Par: toca
Impar: atraviesa

Ejemplo resuelto

Analizar las raíces y el cruce del eje x de f(x) = x(x − 4)².

  1. Igualamos a cero cada factor: x = 0 y x − 4 = 0, por lo que x = 4.
  2. En 0, el factor x tiene exponente 1: multiplicidad impar; la gráfica atraviesa el eje.
  3. En 4, el factor (x − 4)² tiene exponente 2: multiplicidad par; la gráfica toca el eje y vuelve.

Resultado: raíces 0 y 4. La función cruza en 0 y toca en 4.
