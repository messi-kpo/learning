Regla de Ruffini · todos los pasos

Un atajo para dividir por x − a: la misma cuenta que la división larga, pero solo con los coeficientes. En cada paso se resaltan los números que intervienen.

Dividendo 2x⁴ − 3x² + x − 5 Divisor x − 2

    Resultado

    Cociente
    2x³ + 4x² + 5x + 11
    Resto
    17

    Para verificar, el teorema del resto: al dividir P(x) por x − a, el resto es P(a). P(2) = 2·2⁴ − 3·2² + 2 − 5 = 32 − 12 + 2 − 5 = 17 ✓

    Ojo con el signo

    Dividir por x + 1

    Ruffini pide el divisor escrito como x − a. Como x + 1 = x − (−1), acá a = −1. Si en la tabla ponés 1, todo lo que sigue sale mal. El resto del método no cambia:

    1. Bajamos el 2.
    2. 2 · (−1) = −2 → 0 + (−2) = −2
    3. −2 · (−1) = 2 → −3 + 2 = −1
    4. −1 · (−1) = 1 → 1 + 1 = 2
    5. 2 · (−1) = −2 → −5 + (−2) = −7

    Cociente 2x³ − 2x² − x + 2, resto −7. Verificación: P(−1) = 2 − 3 − 1 − 5 = −7 ✓
